# 航空工学 入門〜基礎 体系教材

大学で航空工学を学んでいない方が、航空系の職場に入る前に**全体像と基礎を体系的に身につける**ための教材です。章ごとに独立したMarkdownファイルになっており、順番に読み進めることを想定しています。

## この教材の特徴

- 数式は必要最小限に絞り、**「何を表す式か」**を言葉で説明
- 各章に**練習問題と解答**(解答は折りたたみ)
- 航空業界で頻出する**用語・単位・実務の視点**を重視
- 最後に**配属分野別の学習ガイド**と参考文献

| 期間 | 範囲 | 目標 |
|---|---|---|
| 1〜2週目 | 第1〜3章 | 用語・単位・大気に慣れる |
| 3〜5週目 | 第4〜6章 | 空気力学の理屈を掴む |

## 学習の進め方のコツ

1. **まず通読して全体像を掴む**。細部の理解は後からで構いません。
2. **練習問題は手で計算する**。単位換算と次元チェックの習慣が実務で役立ちます。
3. **用語は英語も併せて覚える**(航空の資料・規則の多くは英語です)。
4. **Python などで簡単な計算スクリプトを書く**と理解が定着します(標準大気、極曲線、航続距離など)。
5. **一次情報にあたる**。規則は改正され、事故事例の詳細は各機関の公開報告書が最も正確です。

## 注意事項

- 本教材は**学習用の入門資料**です。実際の設計・整備・運航の判断には、**所属組織の規程、適用される耐空性基準・規則、メーカーの公式文書**を必ず参照してください。
- 数値(標準大気の値、典型的な効率や比率など)は、概念理解のための代表値です。
- 規則・技術動向(SAF、電動化、無人機規制など)は変化が早いため、最新情報を公式ソースで確認してください。
